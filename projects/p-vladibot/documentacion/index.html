SECCIÓN 01
OVERVIEW

RESUMEN
DEL
PROYECTO

VLADIBOT TELEGRAM es un bot funcional desarrollado en Python que se conecta a la API oficial de Telegram para recibir mensajes, responder comandos y ejecutar polling continuo sin intervención humana.

El proyecto cubre el ciclo completo de desarrollo de un bot: configuración del entorno, manejo seguro de tokens con variables de entorno, registro de handlers, y despliegue en la nube usando Render como plataforma de ejecución continua.

Construido por Vladimir Alba (VLADISYSTEMS) como proyecto de aprendizaje técnico orientado a dominar la integración con APIs externas, automatización de procesos y despliegue en producción.

SECCIÓN 03
ANALYSIS

PROCESO
DE
ANÁLISIS

VladiBot Telegram es la segunda fase de una necesidad real de automatización de comunicación. La primera fase se construyó en Python para WhatsApp, con el objetivo de ahorrar el tiempo de enviar mensajes uno a uno a una base de datos de agentes inmobiliarios, ofreciéndoles un servicio de arreglos locativos.

Ese primer bot funcionó y tuvo resultados reales — pero la mensajería masiva no autorizada va contra las políticas de uso de WhatsApp, y la plataforma sancionó la línea telefónica, bloqueando temporalmente el envío de mensajes. Ahí terminó ese proyecto, pero no el aprendizaje: la experiencia dejó clara la importancia de conocer y respetar las reglas de cada plataforma antes de construir sobre ella.

CRITERIO 01
Pivote informado, no improvisado

La sanción de WhatsApp llevó a investigar Telegram como alternativa con políticas más flexibles para automatización legítima de mensajería.

CRITERIO 02
Caso de uso real, no solo ejercicio técnico

VladiBot se implementó como primera fase de colaboración con una empresa de viajes y turismo. El objetivo no era vender tickets, sino dar respuesta inmediata y orientación clara a personas interesadas en tramitar visas — resolver la demanda de información rápida y bien dirigida sobre el servicio de acompañamiento en ese trámite.

RESULTADO DEL ANÁLISIS
Prueba de concepto validada, sin avance a segunda fase

El bot se probó y cumplió su objetivo técnico de respuesta automática e inmediata. El proyecto no avanzó a una segunda fase de implementación con la empresa, pero deja una base técnica sólida y validada para automatizaciones de atención e información en tiempo real.

SECCIÓN 05
HOW IT WORKS

FUNCIO
NAMIENTO
DEL BOT

El bot opera en 4 pasos secuenciales desde que un usuario envía un mensaje hasta que recibe la respuesta automática.

01
Recepción de mensajes

El polling consulta a api.telegram.org cada pocos segundos. Cualquier mensaje nuevo es capturado como objeto Update.

02
Comando /start

El CommandHandler("start", start) intercepta el comando y ejecuta la función asíncrona start() con el contexto del mensaje recibido.

03
Respuesta automática

update.message.reply_text() envía la respuesta de vuelta al mismo chat. Sin intervención humana — completamente automatizado.

04
Polling continuo

app.run_polling() mantiene el ciclo activo indefinidamente. El Procfile en Render lo reinicia si cae.

bot.py — código real 
import os
from dotenv import load_dotenv
from telegram import Update
from telegram.ext import ApplicationBuilder, CommandHandler, ContextTypes

load_dotenv()
BOT_TOKEN = os.getenv("BOT_TOKEN")

async def start(update: Update, context: ContextTypes.DEFAULT_TYPE):
    await update.message.reply_text(
        "¡Hola tigre! El bot está funcionando en Render 🐅"
    )

if __name__ == "__main__":
    app = ApplicationBuilder().token(BOT_TOKEN).build()
    app.add_handler(CommandHandler("start", start))
    app.run_polling()
