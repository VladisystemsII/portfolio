SECCIÓN 01
OVERVIEW

RESUMEN
EJECUTIVO

VladCRM-COBOL es un sistema de gestión de clientes cuya lógica de negocio central — registro, actualización, etiquetado, historial y reportes — está implementada en COBOL bajo formato libre (GnuCOBOL).

El proyecto conecta esa lógica COBOL con un API Bridge en Python/Flask, una base de datos MySQL y un frontend web — demostrando cómo un sistema legacy puede integrarse a una arquitectura moderna sin reescribirlo desde cero.

SECCIÓN 02

Módulos
Principales

01
Gestión de clientes

Registro y actualización de clientes con validación de teléfono, correo y categoría.

02
Historial de interacciones

Consulta del historial de contacto asociado a cada cliente por teléfono.

03
Reportes batch

Generación de reportes filtrados por categoría y estado, listos para análisis.

04
Etiquetado administrativo

Clasificación de clientes en cliente, prospecto, proveedor, inactivo o prioritario.

05
Ciclo de importación / exportación VCF

Importa y exporta contactos en formato vCard entre el celular y el sistema.

06
API Bridge

Capa Flask que expone cada programa COBOL como endpoint REST para el frontend.
